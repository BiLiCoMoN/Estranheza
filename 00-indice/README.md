# Índice geral

Este índice apresenta as áreas principais do PercevejoWrite e serve como ponto de navegação do repositório.

- [Estudos](../01-estudos/) — domínios de pesquisa e investigação.
- [Estranheza](../01-estudos/Estranheza/) — primeiro domínio de estudos, preservado a partir do projeto original.
- [Escrita](../02-escrita/) — obras, personagens, mundos, ideias e laboratório.
- [Recursos](../03-recursos/) — bibliografia, referências e ferramentas gerais.
- [Arquivo](../99-arquivo/) — materiais arquivados.

O conteúdo detalhado dos estudos permanece dentro de seus respectivos domínios. Este arquivo funciona apenas como índice e não substitui a documentação interna de [Estranheza](../01-estudos/Estranheza/).
