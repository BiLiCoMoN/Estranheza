## Camada Overview (porta de entrada)

O diretório `00-mapa-de-estudos/overview/` funciona como uma camada introdutória e de acesso rápido ao projeto.

- Propósito: oferecer um panorama conciso das áreas principais, com fichas sintetizadas (uma ficha por área) e uma página `overview.md` que atua como porta de entrada para leitores e colaboradores.
- Estrutura principal:
    - `00-mapa-de-estudos/overview.md` — documento de entrada que descreve o propósito e o estado geral do mapa.
    - `00-mapa-de-estudos/overview/01-percepcao.md` … `10-literatura.md` — dez fichas de overview, uma por área, contendo conceitos-chave, leituras sugeridas da curadoria e orientações de aprofundamento.

Use esta camada quando quiser uma visão rápida antes de entrar em leituras mais detalhadas no mapa principal.

## 🧭 Sobre este projeto

Este repositório é um ambiente de investigação interdisciplinar.

O ponto de partida é o interesse pelo **Vale da Estranheza**, mas o objetivo é investigar um território muito mais amplo:

- como percebemos;
- como reconhecemos padrões;
- como identificamos rostos e agentes;
- como atribuímos humanidade;
- como construímos expectativas;
- como interpretamos sinais;
- como determinadas fronteiras produzem estranheza;
- como o estranho pode produzir horror;
- como tudo isso pode ser utilizado conscientemente na construção de narrativas.

O projeto **não parte da premissa de que existe uma única explicação para a estranheza**.

As relações entre as diferentes áreas serão investigadas ao longo do estudo.

# 🧠 Como estudar

O projeto seguirá aproximadamente este movimento:

**Fonte → Leitura → Anotação → Conceito → Relação → Questionamento → Síntese → Aplicação**

Não é necessário seguir uma linha absolutamente linear.

Uma descoberta em uma área pode gerar uma pergunta em outra.

---

# 🔎 Princípio epistemológico

Este repositório diferencia:

### Fonte

O que o autor ou pesquisa efetivamente afirma.

### Evidência

Aquilo que possui sustentação empírica ou documental.

### Hipótese

Uma explicação proposta que pode ainda estar em discussão.

### Interpretação

Uma leitura realizada por um autor ou pesquisador.

### Síntese pessoal

Uma conexão construída durante este estudo.

### Aplicação criativa

Uma utilização de determinado conceito na escrita.

Essas categorias não devem ser confundidas.

---

# ✍️ Para escritores

A investigação científica e filosófica constitui apenas parte do projeto.

O objetivo final é compreender como conceitos relacionados à estranheza podem ser transformados em ferramentas narrativas.

Algumas perguntas recorrentes:

- O que faz algo parecer familiar?
- O que faz algo parecer humano?
- Quando um objeto passa a parecer um agente?
- Como uma expectativa é construída?
- Como uma expectativa pode ser quebrada?
- Como a ambiguidade modifica a interpretação?
- Como um signo adquire significado?
- Como uma fronteira pode ser atravessada?
- Como controlar o que o leitor sabe?
- Como fazer o leitor reinterpretar algo que já viu?
